# quartz-explorer-skin

Фоны-картинки для строк проводника в Quartz 5 (файл и папка выглядят как кнопки) для отдельной темы.
Функционал проводника не меняется.

## Как работает

**Растяжение без искажений (3-slice).** Картинка делится на три части: левый край и правый край
фиксированной ширины и растягиваемая середина. Это делает CSS `border-image` с `fill`: края всегда
остаются в своём размере, растягивается только середина, поэтому при любой ширине окна рисунок
не косится. Пример: `static-placeholders/preview-3slice.png`.

**Разные фоны.** По умолчанию у файлов фон `file.png`, у папок `folder.png`. Чтобы сменить фон
конкретной заметки, добавь ей тег из списка `variants` (по умолчанию `wip`, `new`, `important`):

```yaml
---
tags: [wip]
---
```

Для папки тег ставится в её `index.md`. Если у заметки несколько тегов из списка, берётся тот,
что раньше в списке `variants`. Картинка варианта называется так же, как тег: `wip.png`.

## Установка

1. Залей папку в репозиторий GitHub и выполни `npx quartz plugin add github:ТВОЙ_НИК/quartz-explorer-skin`.
2. Скопируй картинки из `static-placeholders/explorer-skin/` в `quartz/static/explorer-skin/`
   (позже замени их своими, имена файлов те же).
3. В `quartz.config.yaml` добавь плагин (он ничего не рисует, только помечает строки):

   ```yaml
   - source: github:ТВОЙ_НИК/quartz-explorer-skin
     enabled: true
     options:
       theme: buttons
       variants: [wip, new, important]
     layout:
       position: left
       priority: 60
   ```

4. Сделай тему доступной в списке тем (плагин `toolbar-extras`):

   ```yaml
   options:
     extraThemes:
       - { id: "buttons", label: "Кнопки", base: "dark" }
     placeholderThemes: []
   ```

5. Добавь цвета темы в `quartz/styles/custom.scss` (подбери свои):

   ```scss
   :root[saved-theme="buttons"] {
     color-scheme: dark;
     --light: #161826;
     --lightgray: #2a2f4a;
     --gray: #6b7399;
     --darkgray: #c0c6e0;
     --dark: #e6e9f5;
     --secondary: #7aa2f7;
     --tertiary: #bb9af7;
     --highlight: rgba(122, 162, 247, 0.15);
     --textHighlight: #bb9af788;
   }
   ```

## Свои картинки

Каждая картинка одной высоты (она же высота строки, по умолчанию 40px). Левые и правые `slice`
пикселей это фиксированные края, всё между ними растягивается. Настраивается в `options`:

| Опция       | Значение по умолчанию  | Смысл                                                              |
| ----------- | ---------------------- | ------------------------------------------------------------------ |
| `rowHeight` | `40px`                 | высота строки                                                      |
| `slice`     | `20`                   | ширина каждого края в пикселях картинки                            |
| `edge`      | `20px`                 | ширина края на экране (для картинок 2x: `slice: 40`, `edge: 20px`) |
| `imageDir`  | `static/explorer-skin` | папка с картинками относительно корня сайта                        |

Размеры можно переопределить и в `custom.scss`: `--skin-height`, `--skin-slice`, `--skin-edge`.

## Ограничения

- Состояния наведения и текущей страницы сейчас делаются подсветкой (`filter: brightness`),
  а не отдельными картинками.
- Теги берутся из индекса сайта, который хранит только теги, заголовок, дату и описание, поэтому
  произвольные свойства заметок для выбора фона не подходят.
- Подсветка кода использует правила светлой и тёмной тем, у новой темы её нужно настраивать отдельно.
