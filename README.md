# quartz-explorer-skin

Фоны-картинки для строк проводника в Quartz 5 (файл и папка выглядят как кнопки) для отдельных тем.
Функционал проводника не меняется.

## Как собирается фон

Каждый фон состоит из **трёх отдельных картинок**:

| Часть  | Файл             | Что это                                                          |
| ------ | ---------------- | ---------------------------------------------------------------- |
| начало | `имя-left.png`   | левый край кнопки, рисуется в размере `edgeLeft` × `rowHeight`   |
| основа | `имя-middle.png` | середина, растягивается по ширине строки                         |
| конец  | `имя-right.png`  | правый край кнопки, рисуется в размере `edgeRight` × `rowHeight` |

Края всегда остаются одного размера, растягивается только основа, поэтому рисунок не косится при
любой ширине окна. Основа заходит под края на `overlap` (1px), чтобы между частями не было тонкой
полосы.

**Размер файлов не важен, важны пропорции.** Любая картинка масштабируется до заданного размера на
экране. Левая и правая части должны иметь те же пропорции, что `edgeLeft : rowHeight` (по умолчанию
20 : 40). Для чёткости на телефонах нарисуй вдвое больше (40×80) и оставь `edgeLeft: 20px`,
`rowHeight: 40px`. Основа может быть любой ширины (даже 1px), она растягивается.

Пример сборки при разных ширинах и значениях `ends`: `static-placeholders/preview-parts.png`.

## Какие края рисовать (`ends`)

Свойство у каждой темы: `none` (нет краёв), `left`, `right` или `both`. Основа есть всегда.

```yaml
options:
  themes:
    - { id: buttons, ends: both }
    - { id: flat, ends: none }
    - { id: tab, ends: left }
```

(Для одной темы можно по-старому: `theme: buttons` и `ends: both`.)

## Фоны для файлов, папок и особых заметок

Файлам по умолчанию соответствует `file-*.png`, папкам `folder-*.png`. Чтобы сменить фон конкретной
заметки, добавь ей тег из списка `variants` (по умолчанию `wip`, `new`, `important`):

```yaml
---
tags: [wip]
---
```

Для папки тег ставится в её `index.md`. Если тегов из списка несколько, берётся тот, что раньше в
`variants`. Для варианта `wip` нужны `wip-left.png`, `wip-middle.png`, `wip-right.png`.

## Установка

1. Залей папку в репозиторий GitHub и выполни `npx quartz plugin add github:ТВОЙ_НИК/quartz-explorer-skin`.
2. Скопируй картинки из `static-placeholders/explorer-skin/` в `quartz/static/explorer-skin/`
   (удали старые `file.png`, `folder.png` и т.п., если остались).
3. В `quartz.config.yaml`:

   ```yaml
   - source: github:ТВОЙ_НИК/quartz-explorer-skin
     enabled: true
     options:
       themes:
         - { id: buttons, ends: both }
       variants: [wip, new, important]
     layout:
       position: left
       priority: 60
   ```

4. Тема должна быть в списке тем (плагин `toolbar-extras`, настройка `extraThemes`), а её цвета
   описаны в `custom.scss`.

## Настройки

| Опция                   | По умолчанию                    | Смысл                                                             |
| ----------------------- | ------------------------------- | ----------------------------------------------------------------- |
| `themes`                | `[{ id: buttons, ends: both }]` | темы с фоном и их `ends`                                          |
| `variants`              | `[wip, new, important]`         | теги, меняющие фон                                                |
| `imageDir`              | `static/explorer-skin`          | папка с картинками относительно корня сайта                       |
| `rowHeight`             | `40px`                          | высота строки                                                     |
| `edgeLeft`, `edgeRight` | `20px`                          | ширина левого и правого края на экране                            |
| `overlap`               | `1px`                           | на сколько основа заходит под края (убирает полосу между частями) |
| `gutter`                | `4px`                           | свободное место слева и справа от каждой строки                   |
| `mobileGutter`          | `14px`                          | то же на телефонах                                                |
| `padding`               | `6px`                           | расстояние между текстом и краем кнопки                           |

Все размеры можно переопределить и в `custom.scss` переменными `--skin-height`, `--skin-overlap`,
`--skin-gutter`, `--skin-pad`, `--skin-edge-l`, `--skin-edge-r`.

## На телефонах

- Строки отступают от границы окна на `mobileGutter`, так что края не подходят вплотную к его краю.
- Пока окно проводника закрыто, строки скрыты (`visibility: hidden` с задержкой, чтобы они успели
  уехать вместе с окном), поэтому ничего не торчит поверх основного содержимого. Проводник держит
  раскрытые папки видимыми даже в закрытом окне, из-за этого края могли оставаться на экране.

## Ограничения

- Наведение и текущая страница делаются подсветкой (`filter: brightness`), а не отдельными картинками.
- Теги берутся из индекса сайта (заголовок, теги, дата, описание), другие свойства заметок для выбора
  фона не подходят.
- Подсветка кода использует правила светлой и тёмной тем, у новой темы её нужно настраивать отдельно.
